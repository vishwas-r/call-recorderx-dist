3. Optional Google Drive Backup Integration

Call RecorderX operates 100% locally by default. We provide an optional, user-initiated cloud synchronization feature utilizing Google Drive:

  • Google OAuth Consent: To activate cloud backups, you must explicitly connect your Google Account. The app requests access to the drive.file scope to create a dedicated "Call RecorderX" folder and upload call recording audio files into it.
  • Direct Connections: All file transmissions occur directly between your Android device and Google API servers via secure HTTPS. We do not operate any intermediate servers, databases, or third-party web portals, and we never access or store your files or credentials.
  • Token Security: The OAuth access tokens are stored securely in your local device's private storage (SharedPreferences) and are never transmitted to the developer.
